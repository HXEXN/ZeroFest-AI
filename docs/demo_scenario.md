# 3–5분 심사 Demo Scenario

> 화면에 표시되는 모든 수치와 효과는 **Demo Simulation / Sample / Synthetic Data**이며 실제 실증 결과가 아니다.

## 0:00–0:40 · 문제와 차별성

시작 화면에서 `Data → Predict → Decide → Human Approval → Demand Change → Re-predict`를 짚는다.

발표 문장: “ZeroFest는 남은 음식을 처리하는 서비스가 아니라, 남을 재고를 예측하고 운영과 학생 수요를 함께 움직여 남지 않도록 만드는 플랫폼입니다.”

## 0:40–1:30 · Admin

1. `학생회 Control Tower`를 연다.
2. A구역 닭꼬치의 현재 재고 180개, 최근 30분 20개·8팀, 예상 잔여 62개, HIGH를 확인한다.
3. 근거인 최근 판매 감소, 1시간 뒤 강수 80%, 메인 공연 종료를 보여준다.
4. AI Chat에서 “왜 닭꼬치를 할인해야 돼?”를 실행한다.

## 1:30–2:15 · Operator

1. `부스 운영자`를 연다.
2. `1·2·3·5개 주문` 버튼을 설명한다. 한 번 누르면 한 팀의 주문이라 판매량·재고·주문 건수가 한 번에 기록된다. 베이커리 실데이터에서 판매량과 가장 강하게 움직인 변수가 고객 티켓 수(+0.960)였고, 그 변수를 입력 부담 없이 수집하는 설계다.
3. `20% 마감 할인`만 승인한다. 승인 즉시 다음 30분 예측이 24 → 27개로 오르고 예상 잔여가 62 → 47개, HIGH → MEDIUM으로 바뀐다.
4. “AI가 임의 실행하지 않고 운영자가 최종 승인합니다”를 강조한다.
5. 이 상승폭은 모델이 합성 이력에서 학습한 할인 탄력성이다. 화면용 고정값이 아니다.

## 2:15–2:50 · Student

1. `학생` 화면에서 닭꼬치 6,000원 → 4,800원 할인을 확인한다.
2. Mock Map의 A구역 혜택을 보여준다.
3. Quiz와 Stamp는 Core AI가 아니라 향후 수요 라우팅 모듈임을 짧게 설명한다.

## 2:50–3:30 · Closed Loop

1. `Before / After`를 연다.
2. `학생 반응 발생 → 재예측`을 누른다.
3. 할인 적용 상태로 27개가 판매되고 재고가 153개로 줄어든 스냅샷이 **실제로 DB에 기록**되며, 시계가 19:30으로 이동한다.
4. 같은 파이프라인이 바뀐 상태를 다시 읽어 예상 잔여 42개로 재예측한다. 플래그가 아니라 데이터가 바뀌었기 때문에 이것이 진짜 재예측이다.
5. 예상 잔여는 62 → 42개로 32% 줄었지만 위험도는 MEDIUM이다. 한 번의 20% 할인으로 HIGH가 LOW가 되지는 않는다는 점을 그대로 말한다. 루프는 새 상태에서 다시 반복된다.

## 장애 대응

- LLM 키/호출 장애: 실제 DB에 근거한 Local Grounded Chat으로 자동 전환
- Weather API 장애: 버전 관리된 Mock Weather로 자동 전환
- LangGraph import 장애: 동일한 결정론적 노드 순서 fallback
- 데이터가 꼬인 경우: 사이드바 `Demo 전체 초기화` 한 번 클릭

## 기술 질의응답용 화면

`AI · ML · Data Ops`에서 2023–2025 과거 이력 Adapter, 2025 시간 Hold-out, Feature Importance, Model Run, LangGraph Action Queue를 확인한다.

예상 질문 대비:

- **합성 데이터인데 성능을 믿을 수 있나** — 믿을 수 없다고 먼저 말한다. 보고하는 것은 정확도가 아니라 설계 일관성이다. 9개 칸이 독립 시뮬레이션이라 작년 값을 복사하는 오라클의 R²는 -0.216이고, 운영 기준선(직전 30분 유지) 대비 개선폭을 함께 제시한다.
- **왜 하필 이 변수인가** — 시각을 중복 표현하던 변수 5개는 분산팽창계수 무한대라 제거했고, 검열된 행은 학습에서 뺐다고 설명한다.
- **할인 효과는 어디서 왔나** — 합성 데이터에서 메뉴 내 블록 무작위 배정으로 만든 효과이며, 모델이 그 설계값(+21.1%)을 +20.8%로 복원한다고 설명한다.
